# Cognitive Reframer AI

An LLM-powered cognitive reframing prototype built with AWS PartyRock.

The application helps users transform unstructured thoughts into a structured analysis of facts, assumptions, possible cognitive distortions, alternative interpretations, and practical next steps.

## Project Overview

This project explores how large language models can support structured reflection and decision-making through prompt engineering, workflow design, and structured output generation.

## Platform

- AWS PartyRock
- Large Language Models
- Prompt Engineering
- Structured Output Design

## Project Status

This is an educational prototype rather than a production-level mental health application.
