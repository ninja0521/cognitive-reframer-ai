# Prompt Design

## Objective

The prompt is designed to transform unstructured user input into a structured cognitive reframing process.

## Input

The user provides a difficult situation, thought, or interpretation.

## Expected Output

1. Observable facts
2. Assumptions
3. Possible cognitive distortions
4. Alternative explanations
5. A balanced interpretation
6. Practical next steps

## Design Principles

- Separate facts from interpretations
- Avoid clinical diagnosis
- Use clear and neutral language
- Avoid reinforcing unsupported assumptions
- Clearly acknowledge uncertainty
- Provide practical and low-risk suggestions

## Prompt Architecture

The prototype uses a structured workflow that guides the language model through several stages:

1. Identify the main concern
2. Separate facts from assumptions
3. Identify possible cognitive distortions
4. Generate alternative interpretations
5. Produce a balanced reframing
6. Suggest practical next steps

The complete prompt is not included in this public repository. This document presents the design logic and output structure for portfolio demonstration purposes.
